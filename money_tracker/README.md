# Money Tracker

A beginner Python project for tracking income and expenses.

## Features

* Add income and expenses
* Categorize transactions
* View all transactions
* Calculate total income
* Calculate total expenses
* Calculate current balance
* Save and load transactions using JSON
* Handle invalid amounts and menu options

## Requirements

* Python 3

## How to run

Open a terminal in this folder and run:

```bash
python money_tracker.py
```

On some Windows installations, use:

```bash
py money_tracker.py
```

## Data storage

Transactions are stored locally in `transactions.json`.

Do not upload real personal financial records to a public repository.
